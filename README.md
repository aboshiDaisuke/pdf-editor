# PDF Editor

ブラウザ内だけで完結する Acrobat ライクな PDF 編集アプリ。
MuPDF の公式 WebAssembly 版（mupdf.js）を使用し、PDF はあなたの PC の外に出ません（アップロード無し・ネット不要）。

アプリ本体は [`web/`](web/) にあります。詳細は [`web/README.md`](web/README.md) を参照。

## 機能

### ファイル
- PDF 読み込み（ファイル選択 / ドラッグ&ドロップ、**パスワード付きPDF対応**）
- 保存・別名で保存（ダウンロード）
- **最適化して保存**（不要オブジェクト除去による軽量化）
- **パスワード保護して保存**（AES-256 暗号化、閲覧/権限パスワード）
- 元に戻す / やり直し（⌘Z / ⌘⇧Z）
- **印刷**（⌘P）／ **ページのPNG書き出し**

### 編集
- テキスト編集（ページ上の文字をダブルクリックで直接編集、日本語フォント埋め込み）
- テキスト追加（フォント選択・PCフォント追加対応）
- 画像挿入（自動圧縮、選択・移動・縦横比固定リサイズ）
- 図形描画（四角・楕円・直線、ライブプレビュー）
- **スタンプ**（承認済み・下書き・社外秘などのプリセット + カスタム文字）
- **署名**（手書きパッド / テキスト入力 → 透過PNGとして配置）
- **墨消し（リダクション）**（範囲の内容を黒塗りで完全削除）
- **透かし（ウォーターマーク）**（角度・不透明度・色を指定してページ内容に埋め込み）
- **ページ番号 / ヘッダー・フッター**（形式・位置・開始番号を指定）

### 注釈・マークアップ
- ハイライト / 下線 / 取り消し線（テキストに自動フィット）
- フリーハンド（インク）／ 矢印 ／ コメント（付箋）
- 注釈の消去ツール

### ページ整理
- ページ追加・削除（複数選択一括）・並べ替え（ドラッグ&ドロップ）
- 90°回転／別 PDF からページ挿入（結合）／選択ページの書き出し

### 表示・ナビゲーション
- **しおり（アウトライン）パネル**でジャンプ
- 全ページ テキスト検索（⌘F）
- フォームフィールド入力
- ズーム（25%〜400%）・幅に合わせる
- ライト / ダークテーマ切替
- **文書のプロパティ**（タイトル・作成者などの表示・編集）

## 動かし方（ローカル）

```bash
cd web
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開く（`file://` 直開きは不可）。

## デプロイ

`web/` を静的ホスティングに置くだけ（ビルド不要）。GitHub Pages には gh-pages ブランチで公開:

```bash
git subtree push --prefix=web origin gh-pages
```
